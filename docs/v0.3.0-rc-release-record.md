## 授权性质（必须如实读）

这是**维护者以书面一次性指令委托执行代理提交**的授权，不是维护者逐行人工复核。
四条 review 的 `note` 字段都写明了这一点。GitHub 只能证明「这个账号在此刻针对这个提交
写了这段授权」，不能证明操作者是自然人 —— 与 AGENTS.md 里「同一账号的 Comment review
是可审计、不是独立」一致。
