# v0.1.12 验收截图

真实运行的 DSH Web 界面，用 Edge headless 通过 CDP 逐级点进去截图：
插件页 → dsh-ai-debate 详情 → 组件行 → 配置页。全部在**隔离 home**
（`DSH_HOME` 指向临时目录）+ 独立 Edge 配置里完成，**没有碰主人日常 profile**。

| 文件 | 内容 |
| --- | --- |
| `01-plugins.png` | 插件页，「已安装插件」里有 dsh-ai-debate |
| `02-config.png` | 配置页首屏：贴吧账号区、凭据行「已配置 · 末四位 …C333」、`额外可召唤的主人 ID` 里已持久化的值 |
| `03-typed.png` | 真实键盘输入之后：`有未保存的修改` 出现，`保存` 按钮变亮 |
| `04-saved.png` | 点击页面底部「保存」之后：`已保存，后台已使用新值。` |

## 这组截图证明的三件事

1. **配置页真的能打开**（0.1.6～0.1.8 那轮的空白页不复存在）。
2. **表单真的能改**——`03-typed.png` 里输入值和「未保存」标记同时出现。
   0.1.9～0.1.11 做不到这一点：`projection()` 把 `Map` 放进了快照，
   Host 的 Immer store 每次都抛错，`edit()` 从未完成过。整张表单是哑的，
   而 34 项客户端测试全绿——因为假 store 接受任何快照。
3. **保存真的落盘**——`POST /settings` 的请求体是
   `{"set":{"allowedOwnerIds":"…"}}`，响应 200，页面确认；随后刷新页面、
   完全重启 Host，值仍在。

## 这组截图没有证明的

- 贴吧真实帖子的完整流程（读帖、识别争论对象、生成、发表、回读）**仍未验证**：
  本机对贴吧持续 403，本轮没有绕过。
- 没有在主人日常使用的那个 DSH profile 里重启验证过。
