## 三、这条验收能说什么、不能说什么

**能说的**：v0.3.0 的安装包在真实 Desktop 上，从「没有会话」到「复制出逐字一致的已批准
回复」，整条链路是通的；模型走的是宿主正式服务，不是假模型；四种人格与八种打法的控件是
分开的；未确认的候选不能被复制；页面与服务端都不接受任何发表动作。

**不能说的**：

- 真实平台发表 —— 本轮 0 次调用，页面上也没有发表入口；
- 微博真实读取 —— 本轮走的是手动导入这条路径，没有碰平台授权；
- 陌生人能不能自己走通 —— 本轮是我按既定脚本驱动，不是真实用户。
