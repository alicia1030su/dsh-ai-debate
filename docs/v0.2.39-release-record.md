## 三、这次发布覆盖了什么

- 生成结果五态（`valid_draft` / `needs_more_context` / `unjustified_refusal` /
  `invalid_draft` / `technical_failure`），且类型穿过每一层——不是只在顶层有个字段；
- 策略与人格解耦，8 种基于证据的打法；
- 源码包以 Git 提交为权威来源，`--rev` 无效或 Git 缺失时 **fail-closed**，只有显式
  `--allow-working-tree` 才允许本地回落且不得与 `--rev` 同用；
- 凭据扫描的例外从"整目录跳过"改为 `(路径, 确切字面量)` 登记表；
- 扫描命中不再打印凭据原文（只报路径、规则名、行/列）；
- 读不出来的归档条目让整轮扫描失败，不再静默跳过。

## 四、这次发布没有覆盖什么

- **真实 Desktop 未在本轮重跑**：51/51 是 v0.2.39 开发期的结果，不是发布时的复测。
- **真实宿主模型的语义质量没有被证明提升**：盲评三版各 20 次真实调用，没有测出"新版更好"；
  不追溯数字三版均为 0；唯一实证改进是结果可分辨。
- **真实平台发表继续禁用**；微博真实读取仍受授权限制。
- **陌生人试用 0 人**，人工语义评分 0 人。

这几条同时是 v0.3.0 准入的前置缺口，不因 v0.2.39 发布而消失。
