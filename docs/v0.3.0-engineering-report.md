## 二、本轮实际改动

### 2.1 归档完整性（issue #29）

- 新增 `scripts/lib/zip-index.mjs`：索引自洽判定（本盘条数 = 总条数 = 实际遍历条数、
  中央目录结束位置 = EOCD、遍历结束位置 = 声明结束）、重复名、路径穿越、绝对路径、
  非普通文件、资源预算。
- `scripts/lib/archive-verify.mjs` 改为「先判索引再解压」：少报条目、目录长度少报、
  重复名、穿越、符号链接、不支持的压缩方式、超限尺寸、截断全部抛错；目录条目不参与
  逐文件比对，非普通条目单列一类。
- `scripts/scan-archive.mjs`：重复名与路径穿越作为发现报出；TGZ 解压加
  `maxOutputLength`；目录条目去尾斜杠后再判穿越（本轮全量测试发现的回归）。

### 2.2 候选构建

- 新增 `scripts/rc-build.mjs`：pack → source-zip → 双包扫描 → 逐文件核验 → 裸目录安装 →
  写 `MANIFEST.json`（`release: false`）与 `SHA256SUMS.txt`。任何一步失败即非零退出。
- 预发布号核实结论：**当前工具链不支持** `0.3.0-rc.1`（版本检查只接受三段数字，
  `release.yml` 无 `--prerelease`，rc 标签会被打成 Latest）。按约定未修改发布工作流。

### 2.3 文档

- `docs/v0.3.0-capability-matrix.md`：核心闭环 / 平台 / 模型 / 发布物四张表，逐项标注
  已验证、有代码未验证、受限、不可用。
- `docs/v0.3.0-first-use-guide.md`：九步首次使用 + 六类模型错误 + 五态结果处理。
- `docs/v0.3.0-review-kit.md`：20 条匿名人工评分表、真实用户反馈模板、组织者边界。

### 2.4 升级

- 新增 `test/v0300-upgrade.test.ts`：0.2.37 / 0.2.38 / 0.2.39 三个起点可读；旧
  `approved: true` 读出来但没有批准记录（不是新权限）；写回新候选撤销旧批准、不继承；
  旧配置的坏值落回默认。
