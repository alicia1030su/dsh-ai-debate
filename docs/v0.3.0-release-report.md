### 为什么预发布没有走 Release

当前工具链不支持预发布号：

- `scripts/version.mjs` 与 `release-dry-run.mjs` 只接受 `x.y.z`；
- `release.yml` 用 `TAG_VERSION != PKG_VERSION` 校验标签；
- `gh release create` 没有 `--prerelease`，一个 rc 标签会被打成 **Latest 正式版**。

按任务书：修改工作流需要维护者批准，因此改用「明确标识的非公开候选产物」，并在
`MANIFEST.json` 写明 `release: false`。
