# v0.3.0 能力矩阵

> 这份表回答一个问题：**现在能用什么，不能用什么。**
> 状态只用四档：**已验证**（有可复查的真实证据）、**有代码但未验证**、**受限**
> （依赖外部授权或环境）、**不可用**。不写「基本可用」这类无法判定的词。
>
> 更新日期：2026-11-09。基线：v0.3.0 开发分支。

---

## 二、平台

| 平台 | 读取 | 发表 | 说明 |
| --- | --- | --- | --- |
| 贴吧 | 受限 | **不可用（禁用）** | 读取需要登录态；真实发表本轮 0 次，不对外声明可用 |
| 微博 | 受限 | 不可用 | 依赖 `weibo-cli` 与本机授权；未授权时只能手动导入 |
| 知乎 / 小红书 / 抖音 | 不可用 | 不可用 | 只有规划，没有适配器 |

**重要**：历史某次读取成功不等于当前在线。平台能力以「诊断与状态」页的实时探测为准；
离线导入不依赖任何平台。
